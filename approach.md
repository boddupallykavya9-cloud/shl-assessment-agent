# Approach

## Data Collection

Used BeautifulSoup and requests to scrape SHL assessment catalog pages.

## Retrieval

Implemented semantic retrieval using Sentence Transformers and FAISS similarity search.

## Conversational Logic

Built clarification handling for vague queries, comparison support, and off-topic refusal handling.

## Backend

Implemented FastAPI backend with:
- /health
- /chat

## Deployment

Deployed using Render.
